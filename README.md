This project analyzes student academic performance using exploratory data analysis (EDA).

- student_data.csv
- Attributes include gender, parental education, study time, and grades (G1, G2, G3)

- Pandas

- Jupyter Notebook

# Student Performance Analysis 📊

## 📌 Project Overview
This project focuses on analyzing student academic performance using exploratory data analysis (EDA).  
The main objective is to understand how **study time** and **gender** impact students’ final grades.

---

## ❓ Research Questions
1. **Does study time affect students’ grades?**  
2. **Is there any difference in grades based on gender?**

---

## 📂 Dataset
The dataset contains academic and demographic information of students, including:
- Study time
- Gender
- Previous grades (G1, G2)
- Final grade (G3)
- Family and school-related attributes

File used:
- `student_data.csv`

---

## 🛠 Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🔍 Analysis & Insights

### 1️⃣ Study Time vs Grades
- Students who dedicate more time to studying generally achieve higher final grades.
- A positive relationship is observed between study time and academic performance.

### 2️⃣ Gender vs Grades
- The comparison shows **no significant difference** in overall grades between genders.
- Academic performance appears to be influenced more by study habits than gender.

## 📁 Project Structure
# Student Performance Analysis 📊

## Objective
Analyze factors affecting student academic performance using exploratory data analysis.

## Dataset
- Source: UCI Machine Learning Repository
- Contains student demographic, academic, and social features

## Key Questions
- Does study time affect final grades?
- Is there a difference in performance by gender?
- Does family or school support impact grades?

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights
- Students with higher study time tend to score better, though the relationship is not strictly linear.
- Male students slightly outperform female students in final grades on average.
- Support systems like family and school assistance show a positive influence.

## Conclusion
Student performance is influenced by multiple factors, not just study time.
